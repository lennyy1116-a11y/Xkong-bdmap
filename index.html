用户资料

团队协同时显示的名字和头像。地图点位、全部机构列表、人员筛选都会使用这个头像。

轻量版规则：emoji/图片头像用于显示和筛选；同一个用户名会视为同一个 owner。上传头像会压缩成小图存本地，新增点位会带上该头像。

Google Maps API Key

搜索附近机构需要API Key。没有的话地图和手动标记功能正常使用。

如何获取API Key

  1. 打开 Google Cloud Console
  2. 创建一个项目（或选已有的）
  3. 进入「API和服务」→「库」
  4. 搜索并启用 Places API (New) 和 Maps JavaScript API
  5. 进入「凭据」→「创建凭据」→「API密钥」
  6. 复制Key粘贴到上方输入框
  7. （建议）在Key的限制里添加HTTP引用来源限制

⚠️ 需要绑定结算账号（信用卡），每月有$200免费额度，约可搜1万次，日常BD完全够用。

数据管理

数据保存在浏览器本地存储中。建议定期导出备份。

后台：用户/历史数据清理

这里不是删除登录账号，而是按“点位归属人”删除该用户名下的机构数据。删除会同步云端，谨慎操作。

旧版 TCM/TMC 名单导入现在已经没用；新版已改为底层基础诊所池，不需要在“全部人员”里保留。

用户资料

用户名用于区分团队成员；头像用于地图标注显示。同一个用户名在不同设备上会默认合并为同一个人。

⚠️ 当前轻量版没有真正账号密码系统，所以“同名=同一个人”。正式版建议接 Firebase Auth，用不可修改的 uid 做 ownerId，用户名只当显示名。

Google Maps API Key

搜索附近机构需要API Key。没有的话地图和手动标记功能正常使用。

如何获取API Key

  1. 打开 Google Cloud Console
  2. 创建一个项目（或选已有的）
  3. 进入「API和服务」→「库」
  4. 搜索并启用 Places API (New) 和 Maps JavaScript API
  5. 进入「凭据」→「创建凭据」→「API密钥」
  6. 复制Key粘贴到上方输入框
  7. （建议）在Key的限制里添加HTTP引用来源限制

⚠️ 需要绑定结算账号（信用卡），每月有$200免费额度，约可搜1万次，日常BD完全够用。
